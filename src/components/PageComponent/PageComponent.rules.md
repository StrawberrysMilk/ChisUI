# PageComponent 页面规则

本文件定义 `PageComponent` 及所有使用它的业务页面必须遵守的布局、展示和交互规则。新增页面、迁移旧页面或修改现有页面前，必须先阅读本文件。

## 1. 适用范围

以下情况必须遵守本规则：

- 页面导入或渲染 `PageComponent`。
- 修改 `PageComponent/`、`PageComponentTable/`、`PageComponentPagination/` 下的组件文件。
- 将旧项目的列表、查询、分页或操作列迁移到当前项目。

## 2. 页面层级与背景

- 工作区负责唯一一层外部留白和浅灰背景。
- 页面级 wrapper 只负责 `height: 100%`、`min-height: 0` 和必要的 overflow，不得再次添加 padding 形成双层留白。
- `PageComponent` 必须占满宿主可用高度，整个组件区域保持白色背景。
- 查询区、表格区、空白填充区和分页区都属于同一个白色页面面板。
- 表格和分页之间使用明显但克制的浅灰分隔带，不使用多层卡片或重复边框。

推荐页面容器：

```css
.page-view {
  height: 100%;
  min-height: 0;
  overflow: hidden;
  background: transparent;
}
```

## 3. 查询区

- 查询条件放入 `#condition`，页面级操作放入 `#actions`。
- 查询区采用规整栅格和统一间距，标签、输入框和按钮垂直居中。
- 查询按钮使用实心主色按钮；新增等右侧操作默认使用白底、主色边框的描边按钮，除非原业务明确要求其他样式。
- 查询期间按钮必须显示旋转 loading 图标并禁用，禁止重复提交。
- 查询 loading 和表格 loading 应由同一个请求状态驱动，不能出现按钮已结束但表格仍在加载的状态。

示例：

```vue
<Button :disabled="loading" @click="search">
  <Icon :icon="loading ? 'svg-spinners:180-ring-with-bg' : 'lucide:search'" />
  查询
</Button>
```

## 4. 表格与列数据

- 列顺序、字段含义、字典转换和操作权限必须以原业务页面为准，不能仅展示接口原始值。
- 枚举或字典字段必须按业务编码匹配显示文本。例如 `Y/N` 显示“是/否”，`0/1` 显示对应状态文本。
- 图片或 Base64 图标必须通过自定义单元格渲染为图片，不能直接显示 URL 字符串。
- 白色透明图标必须提供原业务要求的对比底色，保证可辨识。
- `PageComponent` 必须将 `#cell` 插槽完整转发给 `PageComponentTable`，不得丢失 `row`、`column`、`value`。
- 没有自定义渲染时才回退显示原始值或 `-`。

自定义列示例：

```vue
<template #cell="{ row, column, value }">
  <template v-if="column === 'status'">{{ statusFilter(row.status) }}</template>
  <img v-else-if="column === 'iconBase'" :src="String(row.iconBase)" alt="应用图标" />
  <span v-else>{{ value ?? '-' }}</span>
</template>
```

## 5. 表格状态

- 数据行统一使用紧凑的 `38px` 行高，不得沿用 VXE Table 偏高的默认行高。
- 每一行必须有 `1px` 浅灰色水平分隔线，保持列表的扫描性；默认不添加纵向网格线。
- 表格加载时必须保留原表格布局，并覆盖半透明蒙层、旋转 loading 图标和“加载中...”文本。
- 禁止在加载时直接卸载整张表格并只显示一行文字，这会造成布局跳动。
- 当前行必须有明确的选中背景；默认可选中首行，点击其他行后切换当前行。
- 当前行背景使用浅绿色，颜色应接近 `#d9f99d`，不得影响文字可读性。
- 表格滚动发生在表格内容区域，不允许页面 body 成为滚动容器。

## 6. 状态列与操作列

- 状态文字使用主色蓝色，无下划线，并保持可点击反馈。
- 操作列必须根据原业务权限与条件完整展示，不得因插槽未转发而显示 `-`。
- “编辑”和普通操作使用蓝色，“删除”使用红色，“设为默认”等次要操作使用蓝色。
- 操作文字保持紧凑、无下划线，不使用大尺寸实心按钮占用表格空间。
- 操作列固定在右侧时必须给出稳定宽度，避免文字换行或覆盖其他列。

## 7. 危险操作确认

- 状态切换、删除、设为默认等有副作用的操作必须二次确认。
- 使用项目已有的 shadcn-vue `Popover` 组合确认气泡，不使用浏览器 `window.confirm`。
- 确认气泡包含黄色警示图标、明确文案、“取消”和“确定”按钮。
- “确定”按钮为主色背景且文字必须为白色；“取消”按钮为描边样式和深色文字。
- Popover 通过 Portal 渲染，相关样式必须能命中 Portal 内容；不要依赖无法穿透 Portal 的 scoped 选择器。

## 8. 请求反馈

- 查询请求显示按钮 loading 和表格蒙层 loading。
- 新增、编辑、删除、状态切换、设为默认等操作开始后显示“处理中...”反馈。
- 所有会调用接口的按钮都必须具备防重复提交机制：优先使用 loading 状态同时禁用按钮。
- 如果操作按钮没有 loading/禁用效果，则其接口请求必须通过 `@/utils/cancelTask` 的 `cancelableRequest` 发起；同一接口的新请求会取消尚未完成的旧请求，避免连续点击产生竞态请求。
- 传给 `cancelableRequest` 的接口函数必须是具名函数，不得传入匿名包装函数；需要在弹窗关闭、页面重置等场景主动终止请求时，使用 `cancelRequest`。
- 已通过 loading 状态禁用的按钮不要求重复使用 `cancelableRequest`，但分页、树节点等仍可连续触发同一接口的入口必须使用它。
- 成功后关闭 loading 提示，再显示独立的成功 Toast；失败后显示接口错误信息。
- 全局入口必须引入 `vue-sonner/style.css`，根组件必须挂载一个 `Toaster`。
- 成功提示不能只写日志，必须在页面上可见。
- 请求异常必须使用 `try/catch/finally` 收口，禁止 loading 永久不结束。

## 9. 分页区

- 分页固定在 `PageComponent` 底部，表格内容区域占据剩余高度。
- 分页区为白色，和表格之间保留浅灰分隔带。
- 显示总条数、当前页和翻页按钮；按钮禁用状态必须正确。
- 分页变化后重新加载数据，并保持表格与查询 loading 行为一致。

## 10. 宿主布局约束

- 应用头部、侧栏、页签栏和工作区尺寸由 `BasicLayout` 统一管理，业务页面不得自行计算或覆盖。
- 工作区使用纵向 flex 布局，页签栏固定高度，内容区 `flex: 1; min-height: 0`。
- 页面不得再次创建模拟页签栏、侧栏或第二层工作区背景。

## 12. 样式组织

- 使用 `PageComponent` 的业务页面应将页面级样式放在同目录 `index.scss`（或页面同名 SCSS）中，Vue 文件只保留模板、逻辑和必要的样式入口。
- 布局、间距、尺寸、对齐等通用样式优先使用 Tailwind CSS class；组件深层选择器、Portal 内容、主题覆盖和业务专属样式使用 SCSS。
- 不得在业务页面重复定义 `PageComponent` 内部布局、表格通用规则或宿主工作区背景。

## 13. 实现与验证清单

完成一个 `PageComponent` 页面前必须确认：

- 只有一层灰色外留白，`PageComponent` 内部完整为白色。
- 查询按钮 loading 正常，表格 loading 为蒙层效果。
- 字典值、图片和业务格式均已转换，不显示原始编码或 Base64 字符串。
- 当前行选中背景可见。
- 数据行高度紧凑且每行都有浅灰水平分隔线。
- 状态和操作列颜色正确，操作权限与原业务一致。
- 所有危险操作都有 Popover 确认。
- 成功和失败 Toast 均可见。
- 所有接口按钮均通过 loading + disabled 或 `cancelableRequest` 防止重复请求与竞态覆盖。
- 分页固定在底部且表格独立滚动。
- `pnpm exec vue-tsc -b` 与 `pnpm build` 通过。
